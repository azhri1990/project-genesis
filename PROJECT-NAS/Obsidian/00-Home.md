## Core principle

> A feature is not complete because a file exists. It is complete when its behavior is executable, tested, documented accurately, and reproducible on a clean environment.

## Operating model

**Local-first → test → document → harden → expand.**

Cloud AI is optional. The target architecture should remain usable without paid cloud AI/API subscriptions or token-credit dependency where practical.

## Current priority

1. Stabilize the runtime.
2. Add model health/discovery and deterministic fallback routing.
3. Add context budgeting/compression.
4. Establish explicit memory retention/redaction rules.
5. Complete security review before remote/plugin/device expansion.
6. Build the cross-platform UI and voice layer.
