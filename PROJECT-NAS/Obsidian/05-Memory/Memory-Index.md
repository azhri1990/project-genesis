# Memory Index

## Purpose

This is the navigation point for PROJECT-NAS memory. Keep durable knowledge organized instead of allowing the vault to become a flat dump of notes.

## Memory classes

- **Architecture** — system boundaries, interfaces, decisions
- **Engineering** — bugs, fixes, tests, deployment procedures
- **AI** — prompts, model routing, context and memory policies
- **Operations** — repeatable workflows and SOPs
- **Decisions** — why a design choice was made
- **Project state** — milestones, blockers, next actions

## Memory rules

1. Store durable, reusable knowledge.
2. Do not store secrets, tokens or credentials.
3. Separate facts from assumptions.
4. Prefer links to source files instead of copying large code blocks.
5. Record decisions with date and rationale.
6. Review stale roadmap notes when implementation changes.
